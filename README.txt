# Leilão de Futebol com Mata-Mata (Lance Inicial em € 0)

## Modificações:
1. **Sem Lance Inicial**: Cada jogador exibido em leilão começa com o maior lance em **€ 0**.
2. **Adição Livre de Valores**: Os participantes podem digitar o valor desejado ou usar botões rápidos (+1M, +5M, +10M, +25M) para definir e enviar seus lances livremente.
